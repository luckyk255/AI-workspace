# AI-workspace

Shared personal workflow for Codex. Keep only non-secret, reusable material here: instructions, task templates, checklists, and documented lessons.

## Use on each computer

1. Clone this repository to the same path when possible.
2. In Codex, open `AI-workspace` as the task workspace before starting work that should use these defaults.
3. For project work, open the project itself. Its local instructions override this repository's defaults; copy only genuinely reusable rules back here.
4. Run `git pull --ff-only` before editing and commit/push your workflow changes after review.

## Security boundary

Do not put API keys, tokens, `.env` files, private customer data, raw production logs, or personal chat exports in this repository.

See [task templates](templates/task-prompts.md) for ready-to-use prompts.
