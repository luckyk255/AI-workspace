# Codex Task Prompts

## Diagnose

```text
在 [项目路径] 排查 [现象]。先只读定位原因，给出代码证据和最小修复方案；没有我确认不要改代码。
```

## Implement

```text
在 [项目路径] 修复 [问题]。保持兼容、不要改无关文件；补直接相关的测试或文档，并区分静态检查、测试和真实环境验证。
```

## Review

```text
审查 [项目路径/PR/文件] 的 [范围]。按严重程度列出可复现的问题；不要直接修改代码。
```

## Explain

```text
解释 [文件或模块] 给有 Python 背景的开发者：先给真实调用链，再解释关键 TypeScript 写法和风险点。
```

## Handoff format

```text
完成：一句话说明结果。
变更：文件 + 关键行为。
验证：已通过的检查；未运行或受阻的检查及原因。
注意：仍需在真实环境确认的事项（如有）。
```
